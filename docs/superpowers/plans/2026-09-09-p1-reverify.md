### 2.1 实现层盲审模板（G1–G13 用，占位符 {PY} {TS} {GID}）

```text
你是一名 1:1 移植审计员。这是只读研究任务：禁止写入、修改、删除任何文件；禁止运行 pytest；禁止执行 git log/git diff/git show。

仓库根：D:\Project\deepseek-harness-win7

TS 权威源（唯一设计基准，逐行通读）：
{TS}

Python 被审移植（逐行通读）：
{PY}

允许的偏离（仅以下两条，其余一切不同都算差异）：
1. Python 3.8.10 限制：禁用 3.9+ 语法（内建泛型 list[str]/dict[str,Any]、str.removeprefix/removesuffix、match/case）；用 typing.List/Dict；asyncio 仅 3.8 兼容写法。
2. Windows 7 SP1 限制：powershell.exe 优先回退 cmd.exe；bash 系不移植；显式 encoding="utf-8"；路径用 os.path/pathlib 规范化。

方法要求：
- 逐函数建立 TS ↔ Python 映射；TS 有而 Python 无、Python 有而 TS 无（自发明行为）都必须报告。
- 对每个共享行为核对：语义、参数默认值、返回值形状、错误类型与错误消息文本、事件/effect 触发顺序、边界条件（空输入/None/越界/并发）、配置键名。
- 每条差异必须给出 TS 侧 file:line 引文 + 代码摘录（3-8 行）与 Python 侧 file:line。没有引文的差异条目无效。
- 判定口径：MUST-FIX=设计不一致（无偏离理由）；ADAPT=上述两条偏离清单强制的等价改写（必须说明是哪条强制）；DEVIATION-PERMITTED=语义可察觉但影响极小、值得记录许可的偏差。
- 不确定行为能否用运行探针裁决的，列入 PROBE 候选并写明探针要构造的场景。
- 禁止打开 docs/ 下任何文件作为依据；证据只能来自你读到的源码。

你的最终回复 = 报告全文（将被原样保存），用以下 Markdown 结构（中文）：

# {GID} 盲审报告

## 映射表
| TS 符号 (file:line) | Python 符号 (file:line) | 状态（1:1 / ADAPT / D#） |

## 差异
### D1: <标题>
- TS: `<file>:<line>` 摘录 ```...```
- PY: `<file>:<line>` 摘录或行为描述
- 判定: MUST-FIX | ADAPT | DEVIATION-PERMITTED
- 影响: <一行>
- 建议修法: <具体到函数/调用点>

## 测试缺口
### T1: <标题> — <缺失钉测的 TS 行为 + 引文>

## PROBE 候选
- D#: <场景与理由>

（若某节无内容，写"无"。不允许空报告；映射表必须覆盖两侧全部顶层函数/类。）
```

方法要求：
