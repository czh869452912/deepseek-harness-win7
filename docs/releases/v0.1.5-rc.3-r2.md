# DeepSeek Harness Win7 v0.1.5-rc.3-r2

上游 `dsh-v0.1.5-rc.3`（`a4c74a91e06b00fe0b0937bde982170c526cc842`）的第二次 Windows 分发修订。保留 [r1 标签与下载文件](https://github.com/czh869452912/deepseek-harness-win7/releases/tag/v0.1.5-rc.3-r1)，新增独立版本及校验清单。

## 修复

- NSIS 的六处 PowerShell 入口使用 `-InputFormat None`，避免 PS2 解析重定向输入，修复本地复现的 `Access to the path is denied`。
- 清理和发布入口保留 PS2 `-File` 的真实失败码；系统组件启动直接保留原生进程句柄，正确采集失败及重启状态。
- 日志追加定位到文件末尾，保留完整 UTF-8 诊断；记录实际 PowerShell/CLR、位数、管理员状态、操作阶段、路径/PID及异常位置。
- 路径检查减少旧 PowerShell provider 依赖，继续拒绝真实权限错误和链接祖先；运行实例保护、补丁顺序和用户文件保留策略不变。
