本批修复 C9-BY 暴露的既有回执消费者清单，不更换原始 Source 身份，不修改业务观察和接受规则。

实际隔离 Python 观察显示，JavaScript 错误边界的两个子进程均新增 8 个 Cordis 预加载模块，来自 `hmr.py`、`include.py`、`loader.py` 的直接导入。LLM 配置的两个子进程均新增 33 个模块：同一 Cordis 拆分、LLM 流组装器，以及 JSONL 持久化初始化导入的历史格式链。逐项核对导入路径后补入明确的固定允许清单；观察器继续独立采集实际模块，校验精确集合、文件字节、子进程身份与完整结果，不动态接受任意导入。
