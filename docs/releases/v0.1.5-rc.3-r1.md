# DeepSeek Harness Win7 v0.1.5-rc.3-r1

这是上游 `dsh-v0.1.5-rc.3`（`a4c74a91e06b00fe0b0937bde982170c526cc842`）的 Windows 分发修订版，继续作为预发布提供。原 `v0.1.5-rc.3` 标签、文件和历史资格保留，新版本使用独立标签、产物及校验清单。

## 修复

- #7：Web 版文件夹选择器使用临时置顶 owner，避免系统对话框被普通浏览器窗口遮挡；选择、取消和请求中止后回收原生窗口及子进程。
- #6：安装器区分后台实例占用和检查脚本失败；占用时显示 PID/程序路径，检查失败时提供退出码和日志。替换旧 CLR 不支持的哈希清理及开始菜单路径接口。
- 产品版本、Portable 和 Desktop 文件名使用 `0.1.5-rc.3-r1`。本版更新器支持 Windows 修订号的严格校验及排序，防止重复更新或回退到较早修订。
- 修复干净 CI 环境遗漏生成 `ui-dockkit/lib` 的准备步骤，并从原始前端 sourcemap 检查准备清单的覆盖范围。标签发布继续保留预发布标记。

#6 没有完整现场错误日志，不能将所有安装失败归为单一根因。运行中程序的保护不会被绕过；关闭浏览器或隐藏到托盘不等于 Host 退出。升级前保存工作，退出应用及对应 Host，备份 `DSH_HOME` 和自定义会话目录。

## 验收范围

源码修复已完成真实 WinForms 置顶、中文/含空格路径确定返回、取消/中止、实例占用、清理回滚及补丁顺序的定向验证；修订号另覆盖 Electron22/Node16 的签名更新、排序和无效版本拒绝。发行验收必须另外绑定本次冻结提交和精确分发文件，不复用旧版资格。

当前 Windows 上的自动化验证不等于 Win7 SP1 的全部补丁/重启、位数及多屏浏览器矩阵认证。旧版用户的 Win7 实测不自动覆盖本修订；既有 ACL issue #4、Source 例外、插件 ABI 与内网更新部署边界继续披露，见[已知差异](../known-differences.md)。

问题分析和后续 Win7 验收矩阵见[修复记录](../research/2026-11-03-issues-6-7-fix-plan.md)。
