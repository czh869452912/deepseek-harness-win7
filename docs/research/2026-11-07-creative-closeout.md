## 一比一结论的边界

已知代码缺口的修复不等于任意插件、任意 JavaScript 或任意 Windows 环境都已完成等价认证。以下项目继续单列：

1. Client 使用 Acorn/QuickJS 的 Win7 编译适配；已知函数体、using、正则差异有固定原版差分，完整 V8 语法和错误措辞并非数学上的全输入等价证明。浏览器激活仍由真实前端引擎负责。
2. 进程桥覆盖实际 Context、事件、工具、RPC、可变/冻结 JSON、迭代、异步等待、取消与卸载。任意第三方 Python 对象的类身份、特殊方法、服务 ABI 和所有长期引用图不是已认证合同；共享状态仍按 Run 寿命保留，128 次 RPC 的无增长结果不能推广为所有服务的长期内存界限。
3. Win7 SP1 真机、嵌套 Job、不同桌面启动环境需要当前候选的实际验收。现代 Windows 上的 x86/x64 或 Chromium 108 结果不能替代真机。
4. 技能资源路径在启动层按包名/路径处理仍有耦合，当前未发现新的功能故障；可选发行与共享租约不计入原版默认设计。

因此，本轮可以关闭已验证的具体实现差异，不能把它扩大为“除语言外所有分支完全等价”，也不把旧发行包重标为当前候选。
