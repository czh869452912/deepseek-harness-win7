Windows 7 离线环境升级

Standard 版不会修改 Windows 系统组件。基础界面可继续使用；PowerShell 5.1 和 .NET 4.7.2 可改善终端与自动化兼容性。升级 Windows 组件可能需要重启。

  1. 确认系统已安装 Windows 7 SP1。保存工作，并退出 DeepSeek Harness 主窗口和托盘图标。
  2. 将同级分发的 dsh-win7-offline-upgrade.zip 完整解压到本地普通文件夹。不要直接从 ZIP 内运行脚本。
  3. 右键 upgrade-win7.bat，选择“以管理员身份运行”。脚本自动选择当前系统的 x86/x64 补丁，只安装缺失组件。
  4. 处理顺序为 SSU KB4490628 → SHA-2 KB4474419 → D3DCompiler47 KB4019990 → .NET 4.7.2 → WMF 5.1。若提示需要重启，请重启后再次运行同一脚本；未完成重启前不会继续后续补丁。
  5. 如果原有 WMF 3.0，请先依照微软说明移除该版本。未知安装错误会停止升级，保留日志，不自动卸载系统组件。
  6. 完成后重新启动 DeepSeek Harness。AIO 安装包提供同一组件链，也可作为替代入口；需要重启时，重启后再次运行安装包。

日志位置由脚本输出，默认保存在临时目录。你的 DSH_HOME 设置、插件和会话不会参与系统升级。

安装失败时先区分原因

  • 提示仍在运行，并列出 PID/程序路径：退出托盘中的 DeepSeek Harness；Web/CLI 版需要停止对应的 Host。关闭浏览器页面不会停止后台服务。仅关闭路径属于本次安装的进程，再重新运行安装器。
  • 提示无法检查运行实例：查看安装器“Details”和提示的日志文件，保留退出码及错误原文；这条提示本身不能证明有后台实例。在未更新的 Win7 上，先按上面的步骤运行独立离线升级包，按要求重启后重试。
  • 提示组件安装失败：保留日志，不要反复安装相同补丁；确认包与系统架构匹配，并检查是否仍有待完成的重启。

Offline setup in English

Standard installs the application without changing Windows components. Extract the separately distributed dsh-win7-offline-upgrade.zip, then right-click upgrade-win7.bat and choose Run as administrator. Save your work first. The script selects x86/x64, skips installed packages and stops before the next package when a restart is required. Restart Windows and run the same script again to continue. Remove WMF 3.0 following Microsoft guidance before installing WMF 5.1. Unknown failures stop the chain and retain the log.

The same prerequisites are available in the AIO installer. This upgrade changes Windows components and does not replace your application settings or sessions.
